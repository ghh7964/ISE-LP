## 발표 자료 열기
- 온라인: https://ghh7964.github.io/ISE-LP/ (발표자 화면은 P 키)
- `발표/index.html`을 더블클릭해서 엽니다. Windows는 `발표/열기.bat`, macOS는 `발표/열기.command`를 실행해도 됩니다.
- 라이브러리를 CDN에서 받아 오므로 인터넷 연결이 필요합니다.
- 마크다운을 고친 뒤에는 `python3 발표/sync.py`를 실행해 스냅숏을 갱신합니다.
